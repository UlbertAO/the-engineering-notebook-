# LLM Engineering

A practical exploration of building applications and systems powered by Large Language Models (LLMs).

This series starts with the fundamentals of how LLMs process prompts and gradually moves toward the engineering problems that emerge when LLMs are used in real applications context management, memory, structured outputs, tool calling, AI agents, evaluation, and security.

The goal is to build a practical mental model of how LLM-powered systems work and how to design them to be more reliable, predictable, and secure.

The series is continuously evolving, and additional topics will be added as the field and my understanding develop.
